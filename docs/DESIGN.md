# GuitarBridge 设计规范

像一本练习簿，而不是一个仪表盘：分区靠留白和细线，强调只用一种颜色，数字一律等宽。

设计稿画布：<https://claude.ai/artifact/4F2DJaEVZVGAvcofc4vxjU>（桌面答题中 / 结果揭晓、手机答题、深色仅品记、本轮小结、规范）。

## 颜色

所有颜色来自 `lib/core/theme.dart` 的 `GbColors`，组件里通过 `context.gb` 读取，不写死色值。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | #FAF9F5 | #1E1D1B | 纸面 |
| `sunken` | #F1EFE8 | #262522 | 指板底 |
| `hairline` | #E5E2D9 | #34332F | 1 px 分区线 |
| `ink` / `textPrimary` | #1F1E1B | #ECEAE3 | 正文、基准音、首答对 |
| `textSecondary` | #57554F | #B8B4AA | 次要文字 |
| `textMuted` | #75736C | #8F8B82 | 注释（在纸面上 ≥ 4.5:1） |
| `accent` | #B5552F | #DB7C5A | 唯一强调：主按钮与“当前”状态 |
| `correct` | #2E6F4E | #74C394 | 答案 |
| `wrong` | #A8402E | #EA8A78 | 试过 / 未答出 |

对错的绿与红只出现在指板和计分格里，并且总配一个形状（实心、描边、斜线），不只靠颜色区分。

## 字体

全部随包发布（`assets/fonts/`，SIL OFL 1.1，`tool/subset_fonts.py` 生成子集）。

- **宋体 Noto Serif SC 600**：题目中的音名（64 / 48 px）、标题与结论（40 / 28 / 22 px）、揭晓时的音程名（斜体）。
- **黑体 Noto Sans SC 400/500/600**：正文与按钮（15 / 14 / 13 px）。
- **等宽 JetBrains Mono 400/500**：题号、品号、计时、按键提示（11–14 px），中文回退到黑体。用 `AppTheme.monoStyle()`。

## 指板

- 画成乐器：1→6 弦粗 1 / 1.2 / 1.5 / 2 / 2.4 / 2.8 px；品丝 1.5 px；琴枕 3 px；0 品在琴枕左侧单独一列。
- 只标调内音，调外音留空。调内音 24 px 白底细边圆；基准音 30 px 墨色实心；试过 30 px 红色描边；答案 30 px 绿色实心。
- 品记在弦与弦之间：3/5/7/9/15/17/19/21 单点，12 品双点（仅品记模式绘制）。
- 练习范围外的品位降到 45% 不透明，并注明“范围外也算，但不出题”。
- 手机行高 44 px、品宽 ≥ 44 px；新题自动滚动到基准音。

## 页面结构

1. 页眉：宋体文字标题；右侧“连续 N 天”“统计”“设置”文字链接，没有图标按钮。
2. 设置条：上下细线；调性与音阶（宋体）/ 调弦 / 难度与品位范围（等宽）都是可点的文字菜单；右侧“音名 · 级数 · 仅品记”下划线标签和“品号”复选框。训练中锁定调性，写明“本轮进行中，调性已锁定”。
3. 题目区：没有卡片。等宽题号 → 基准音（宋体）→ 目标空格（陶土色虚线）→ 一句具体反馈 → 操作。右侧是逐题计分格（■ 首答对、□ 重试后对、／ 未答出）和带点线引导的统计。
4. 指板区：上方细线，说明一句加图例。
5. 手机：答题时操作固定在底部栏；计分格缩成一排 10 px 小格放在题号旁。

## 控件

一屏只有一个实心主按钮（陶土色）；次要操作用细描边；退出类操作用文字。按键提示直接写在按钮里（等宽小字），不另做浮层。

## 去 AI 味

| 主题 | 不做 | 改成 |
| --- | --- | --- |
| 分区 | 每块内容都套一张圆角卡片 | 留白和 1 px 细线；只有弹层有边框和阴影 |
| 标签 | 彩色小圆点眉题、胶囊标签、渐变底色 | 等宽小字写题号和数据 |
| 进度 | 进度条加百分比圆环 | 逐题计分格 |
| 文案 | “开启你的练耳之旅”“太棒了！” | 短句、乐理术语、具体数字：“A4 偏低，还可以试 2 次。” |
| 导航 | 一排方形图标按钮 | 文字链接 |
| 数字 | 数字和正文混用同一字体 | 数字等宽，音名宋体 |
| 指板 | 一张表格，每格一个色块 | 弦、品丝、琴枕、品记 |
| 装饰 | emoji、奖杯、火焰、庆祝动画 | 一句宋体结论：“十题里，七题一次听对。” |

## 图标

陶土色方块上，一个实心音（基准）和一个空心圈（目标）由一道连音线连起来，背后衬三根琴弦。连音线在乐谱里表示“把两个音连起来”，也就是 GuitarBridge 里的 bridge。

- 源：`tool/icon_svg.py`（`rounded` 应用图标、`full` 满版用于 maskable 与 iOS、`small` 去掉琴弦并加粗用于 16–32 px、`mac` 带 macOS 图标网格边距）。
- 生成：`python3 tool/generate_icons.py`（需要 Pillow 和带 Chromium 的 Playwright），一次写出网页 favicon（SVG + PNG）、PWA、Apple 触控图标、Android、iOS（无透明通道）、macOS 与 Windows `.ico`。
- maskable 图案必须落在中心 80% 的圆内。
