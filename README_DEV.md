# GuitarBridge 北极星持续迭代协议 (v2.0)

## 1. 终极使命 (The North Star)
打造工业级、可商业化、且懂吉他手灵魂的视唱练耳 App。

**核心逻辑锚点：**
- 调性建立 → 物理锚点 → 听觉挑战 → 寻址判定

## 2. 禁止"懒惰"判定算法

**[算法层]**
- 所有音程逻辑（3度、5度、7度）必须覆盖全部 12 个半音
- 支持所有已定义的特殊调弦

**[测试层]**
- 必须存在 XCTest 证明逻辑在同音异弦（Enharmonic）情况下 100% 准确

**[视觉层]**
- 指板必须具备物理真实感（17.817 间距公式、琴弦粗细差异、金属材质高光）

**[工程层]**
- 代码必须符合 Swift 6 严格并发检查
- 严禁线程安全隐患

## 3. "自律式"迭代工作流

每轮迭代必须执行：

1. **审计 (Audit)**：对比当前代码与协议，找出未完美的细节
2. **攻击 (Attack)**：寻找边界 Bug（15品连点10次、采样未加载就点击）
3. **重构 (Refactor)**：架构太乱立即局部重构
4. **进化 (Evolve)**：基础功能稳后自动开发高级功能

## 4. 状态回报模板

每轮汇报格式：
- 本轮攻克的硬核点：[具体算法/Bug修复]
- 自我批判：[哪些代码写得还不够优雅？哪些 UI 细节还是"毛坯房”？]
- 下一轮自动执行目标：[必须是具体的、可量化的代码任务]
